# 시니어 도우미 (목업 프로토타입)

쇼핑 중 복잡한 화면을 캡처해서 보여주면 AI가 쉬운 말로 설명해주는 서비스의 UI 목업입니다.
실제 AI 분석 로직은 없고, 화면 흐름과 예시 답변만 보여주는 정적 프로토타입입니다.

## 화면 흐름
1. 홈 — 서비스 소개
2. 화면 보여주기 — 스크린샷 업로드(목업)
3. 질문하기 — 텍스트/음성 입력
4. 답변 — 결제금액 / 이유 / 추가조건을 카드로 정리
5. 비교하기 — 두 상품 크기 비교 목업

## 실행
별도 빌드 없이 `index.html`만으로 동작합니다. GitHub Pages로 바로 배포 가능합니다.
